# Jack's Car Rental: Optimal Policy Using Value Iteration

## Project Overview

This project explores Jack's Car Rental Problem, a classical Markov Decision Process (MDP) in reinforcement learning. The objective is to determine an optimal policy for transferring cars between two rental locations to maximize expected long-term rewards.

The implementation uses Python to model stochastic rental requests and returns, compute expected rewards, and apply value iteration to determine a policy for car transfers.

## Methods and Implementation

- **Poisson Distribution:** Modeling rental requests and returns at two locations.
- **Markov Decision Process:** Representing states, actions, and expected rewards.
- **Value Iteration:** Iteratively updating state values and selecting actions.
- **Policy Optimization:** Determining the number of cars to transfer between locations.
